물음표 — 우리 반 공부 게시판

실행: index.html 파일을 Chrome 또는 Edge로 여세요. 설치와 외부 라이브러리가 필요 없습니다.

1. 공부 고민 게시판: 익명 질문, 답변, ‘나도 궁금해요’, 답변 반응을 사용할 수 있습니다.
2. 화면 위 ‘체험 역할’을 바꾸면 친구나 가상 선생님으로 답변할 수 있습니다.
3. ‘보충이 필요해요’ 횟수는 해당 답변을 작성한 역할에서만 화면에 표시됩니다.
4. 1:1 질문: 학생 역할로 질문을 저장한 뒤 답변자 역할로 전환해서 답변하세요.
5. 답변자 역할에서 공개에 동의해야 학생 역할의 ‘익명 공개 검토하기’가 활성화됩니다.
6. 비공개로 마친 대화는 자료집에 등록되지 않습니다.
7. 공개할 때 정리본을 직접 수정하고 개인정보 확인에 체크하세요.
8. 공개된 글은 자료집에서 과목, 단원, 질문과 답변으로 검색할 수 있습니다.

구성: index.html 한 파일에 HTML(화면), CSS(디자인), JavaScript(동작)를 담았습니다.
데이터는 브라우저 localStorage에 저장되어 새로고침 후에도 남습니다.
브라우저, 사용자 프로필, 파일 위치 또는 접속 주소가 바뀌면 저장 데이터가 다를 수 있습니다.

이 버전의 범위
- 학교 인증, 계정, 실제 사용자 간 전송, 서버는 구현하지 않은 로컬 체험판입니다.
- 누구나 역할을 바꿀 수 있으므로 개인정보나 실제 비밀 대화를 입력하지 마세요.
- 익명 표시와 화면상 접근 제한은 보안 기능이 아닙니다. 모든 역할의 데이터가 같은 브라우저에 있습니다.
- 선생님과 예시 답변은 가상 데이터입니다. ‘교사 확인’도 역할 체험입니다.
- 자동 익명 처리는 일부 정규식 치환입니다. 모든 이름과 개인정보를 탐지하거나 AI로 요약하지 않습니다.
- 실제 운영에는 학교 계정 인증, 서버 권한 검사, 데이터베이스, 개인정보 검토가 필요합니다.
